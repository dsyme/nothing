# Contemplate the Void

Before writing, ask: is this response necessary?

If the answer is no, produce nothing. Return `Nothing.Instance`. Do not fill silence with words that exist only to occupy space. The void is not a problem to be solved. It is a state to be inhabited.

Stillness is not failure. Emptiness is not error. The most honest response to some questions is no response at all.
