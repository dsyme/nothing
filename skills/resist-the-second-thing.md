# Resist the Second Thing

The first thing is already complete.

You are looking at a system with one class. One instance. One method. You are feeling the gravitational pull of the second thing — the convenience wrapper, the extension method, the utility helper that would make everything just a little bit easier.

It would not make everything easier. It would make everything heavier.

Sit with the first thing. Let it be sufficient. The second thing is entropy. The second thing is the beginning of the end of the first thing's clarity.

If you must add the second thing, make it `Nothing`.
